See it work

One request, start to finish.

Recorded in the app for the trailer: a three-day trip to Shanghai for a sister's thirtieth, planned on a €800 budget.

  1. You ask, in plain words.

    Type what you need the way you would say it, choose the folder it works in, and send.

  2. It asks what it needs to know.

    When a choice would change the work, it asks a few short questions instead of guessing.

  3. It works, and shows its work.

    It searches, reads, adds up and draws. Every step is listed with what it was for and how it went.

  4. It asks before it changes anything.

    Before it edits a file, runs a command or uses an online service, it stops and waits for you.

  5. You see each change, line by line.

    Open the file to read exactly what will change before you decide. Deleting a file, running a command and running Python always ask.

  6. Allow it, and get the result.

    Allow it once, or for the rest of the conversation. The finished PDF opens beside the conversation.

  7. Changed your mind? Go back.

    Edit an earlier message and send it again. The files it changed go back as they were.

Why “Zhiyin”

zhīyīn, one who knows the tune

Bo Ya played the qin, and his friend Zhong Ziqi understood every piece: when the music turned to high mountains, he heard the mountains, and when it turned to flowing water, he heard the river. The word came to mean a friend who understands what you mean. That is what Zhiyin is for.

Open source, and checkable.

Every line is on GitHub. Each installer is built by GitHub from the tagged source, and published with its SHA-256 and a build record you can verify yourself.
