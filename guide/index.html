Setup guide

From download to your first task.

Six short steps. You need a Windows PC and, for the AI itself, about $5 of credit. Web search has a free monthly allowance.

  • A 64-bit Windows PC
  • An AI provider account with $5 of credit
  • A free Tavily key, for web search

1

Install Zhiyin

  1. Download the installer (%VITE_RELEASE_SIZE%), or take it from the newest release on the Releases page.
  2. Open the downloaded file. Windows shows “Windows protected your PC”, because the installer is not code-signed yet. Select More info, then Run anyway.
  3. Follow the installer's steps.
  4. When Zhiyin first opens, it asks what you plan to use it for. Select the cards that fit, then Make it yours, or Start exploring to skip.

Two free programs it also uses

  • Edge or Chrome, to open web pages. Edge comes with Windows.
  • Git for Windows, to run shell commands (commands typed for Windows to carry out) and to work with Git.
2

Connect an AI model

The thinking behind Zhiyin is done by an AI model, which runs on a company's servers. Zhiyin reaches it with an account of yours. OpenRouter gives you access to many AI models from different companies with one account, and is the simplest place to start: the steps below use it. You buy credit in advance, and each request Zhiyin sends uses a little of it, depending on the model. To use an account with the company that makes a model instead, see the steps after these.

An API key is like a password that lets Zhiyin use your account with a provider.

  1. Create an account at openrouter.ai.
  2. Add credit on the Credits page. $5 is enough to start.
  3. In Zhiyin, open the Model page: select ••• next to Your preferences at the bottom of the sidebar, then Model. Or press Ctrl + ,.
  4. Under Provider, choose OpenRouter, then select Add a key. Get a key on OpenRouter opens the page where keys are made. Create one there and copy it: it starts with sk-or-v1-.
  5. Paste it under Paste your key and select Save key. Zhiyin keeps it in Windows Credential Manager, where Windows keeps passwords, and sends it only to OpenRouter.
  6. Choose a model in the list, then select Save at the top of the page. Leave Any provider ticked, as the page recommends.

Reading the prices

Each model shows two prices per million tokens: what Zhiyin sends (“in”) and what the model writes (“out”). A token is a small piece of a word. Order by and filters such as Lower cost help you compare.

Buying credit

On OpenRouter, one purchase is between $5 and $25,000. Paying by card adds a 5.5% fee, at least $0.80. Unused credit may expire 365 days after you buy it.

Free models

On OpenRouter, models whose name ends in “(free)” cost nothing, within limits: 50 requests a day, or 1,000 a day once you have bought $10 of credit, and 20 a minute. One task can take many requests, so $5 of credit is the simpler start.

OpenRouter's prices and limits checked on 13 October 2026.

Or use the company that makes the model

Zhiyin also reaches a model on its maker's own platform, with an account and a key from that company: Anthropic, OpenAI, Z.ai, DeepSeek, Kimi, MiniMax, Xiaomi MiMo, Qwen or Mistral. That company bills you, at its own prices.

  1. On the Model page, under Provider, choose the company.
  2. Z.ai, DeepSeek, Kimi, MiniMax, Xiaomi MiMo and Qwen each run two platforms. Choose yours with the switch beside the company's name: International or Mainland China. Each platform has its own key, and Mainland China lists its prices in yuan.
  3. Select Add a key. The button Get a key on with the company's name opens that platform's page where keys are made. Paste the key and select Save key.
  4. Choose a model in the list, then select Save at the top of the page.

With any provider, Billing, beside the saved key, opens that platform's page for your balance and credit. Change key replaces or removes the key.

3

Choose a folder

Zhiyin works in one folder at a time, and reads the files in it without asking. For a first try, a new empty folder works well.

  1. In the message box at the bottom of the window, select Choose a folder.
  2. Select Choose a folder… and pick the folder in the window that opens. The same button switches folders later.
4

Turn on plugins

A plugin adds know-how and tools for one kind of work. Select Plugins at the top of the sidebar, select a plugin, and use the switch beside its name to turn it on or off. The cards you chose on the first screen turned on the matching plugins. A plugin that is on is used only when a task needs it.

  • Full-Stack Software Engineering

    Designs, builds, tests and reviews software, with Git, a browser for testing pages, and GitHub.

  • Technical & Academic Publishing

    Writes and typesets papers and reports with sound citations, compiles them to PDF, and finds research papers on alphaXiv.

  • Data Science & Business Intelligence

    Explores, cleans and explains data, in a Python environment of its own.

  • Deep Research & Synthesis

    Researches a question across many sources and writes a report with citations, using Tavily web search.

  • 3D & Rendering

    Builds 3D scenes and renders them, in a Blender that Zhiyin installs and runs on your PC.

Under Connectors, a plugin lists the services and programs it uses. One that needs a program, such as the Python environment or the 3D studio, shows Set up: select it to see what will be downloaded and how large it is, then Install. Blender, for the 3D studio, is about 400 MB.

5

Add web search, and other services

A connector to an online service needs its own key, made on that service's website. Each one is optional, but web search is the one most tasks benefit from.

Tavily, for web search

Free · no card needed

Tavily is what lets Zhiyin search the web, through the Deep Research & Synthesis plugin. Its free plan gives 1,000 credits every month, with no credit card required. A basic search uses 1 credit and an advanced search 2.

  1. Sign up at tavily.com.
  2. Copy your API key from your dashboard at app.tavily.com.
  3. In Zhiyin, open Plugins, select Deep Research & Synthesis, and turn it on if it is off.
  4. Under Connectors, select Settings or Set up next to Tavily.
  5. If the window asks How Zhiyin gets access, choose Paste an access token.
  6. Paste the key into the API key box and select Save token. Zhiyin checks it and shows Connected.

The same window offers Sign in with an account too, which opens Tavily's sign-in page in your browser, with nothing to copy.

GitHub, for software work

In Full-Stack Software Engineering, GitHub works with your repositories, issues and pull requests, using a personal access token: a key with the permissions you choose. With the plugin on, select Set up or Settings next to GitHub, then Open GitHub to make one; the window says which permissions to give it. Paste the token and select Save token.

alphaXiv, for research papers

In Technical & Academic Publishing, alphaXiv finds research papers and reads their full text. With the plugin on, open alphaXiv's window the same way. Choose Sign in with an account, or Paste an access token to use an API key made under Settings > API Keys on alphaxiv.org.

Tavily's free plan checked on 13 October 2026.

6

Give it a task

Type what you need in the message box and press Enter. New task in the sidebar, or Ctrl + N, starts another conversation.

While it works

The message box stays open: type more and press Enter to add to the current work, which Zhiyin reads at its next step. Take back returns it to the message box. While the model is only thinking, Send now sends it at once, and Answer now asks the model to answer directly. With the message box empty, the square button stops the task.

When it asks

Before Zhiyin changes a file, runs a command or uses a connector, it asks, showing what the action is, what it can do, and the exact command or the files that change. Select a file to see the change line by line. Zhiyin says marks the AI's own explanation, which can be wrong, so check what will run.

Allow once
This action runs.
Deny
It does not run. You can tell Zhiyin what to do instead, then select Confirm denial.
Allow for this conversation
Offered for changes to files in one subfolder, for one connector tool, and for changes to the scene open in the 3D studio: what it covers runs without asking for the rest of the conversation. To take it back, select ••• next to the conversation in the sidebar, then Permissions, then Revoke.

Deleting a file, running a shell command, running Python and running a Blender script always ask.

What it cost

Select ••• next to Your preferences, then Usage. The page shows your requests by day and by model, and what they cost by day and by conversation: the provider's own figure, or an estimate from its price list.

How much it keeps in mind

The small ring in the message box shows how much of the conversation Zhiyin keeps in mind. Select it to choose Low, Medium (the default) or Ultra: a larger budget keeps more of a long conversation and costs more per request. Compact summarises older messages to save room.

If something goes wrong

Zhiyin says what happened, with a button for the next step. The messages below name OpenRouter; with another provider, they name that one.

“Add an OpenRouter API key on the Model page” or “OpenRouter rejected the API key”
Select Update API key and paste a key.
“Choose a model on the Model page”
Select Choose a model.
“The OpenRouter account is out of credits”
Select Add OpenRouter credits, add credit, then select Try again.
A connector's window says the service refused the saved key
Make a new key on the service's site and paste it there.
The Plugins page says “Shell commands are unavailable”
Select Get Git for Windows, install it, then select Check again.
